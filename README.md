# Spotlight Advertising Website

A premium modern outdoor advertising company website built with Next.js, React, Tailwind CSS, and modern frontend best practices.

The project is designed to provide a high-end digital presence for an advertising company, showcasing branding services, outdoor campaigns, billboard advertising, digital displays, marketing solutions, and client engagement.

# Installation Guide

## 1. Clone Repository

```bash
git clone https://github.com/yourusername/spotlight_adv_project.git
```

---

## 2. Navigate to Project

```bash
cd spotlight_adv_project
```

---

## 3. Install Dependencies

Using npm:

```bash
npm install
```

Using yarn:

```bash
yarn install
```

---

## 4. Run Development Server

```bash
npm run dev
```

Application runs on:

```bash
http://localhost:3000
```

---

# Build For Production

```bash
npm run build
```

---

# Start Production Server

```bash
npm start
```

---

# Environment Variables

Create a `.env.local` file in the root directory.

Example:

```env
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_COMPANY_NAME=Spotlight Advertising
```
